Aliquot sequences starting under 10000

In this table we summarize the present state of aliquot sequences starting with under 10000. In it, we show the main sequences whose status is yet unknown (by main we mean that all the other sequences with unknown end merges with any sequence in the table; in this cases, we only show in the table the one that starts in the smaller number). We also include the number of decimal digits of the last term reached for each sequence and the guide in that stage.

The table has been build with the calculus of:

  • Wolfgang Creyaufmueller and Paul Zimmermann for the sequences starting in the numbers 276, 552, 564, 660, 966, 1074 and 1134 (these values can be out of date in this table).
  • Manuel Benito and Juan Luis Varona for all the other starting values.
Also, we must acknowledge the help of:
  • Christophe Clavier and Eric Brier, who, by using an home made ECM implementation, found about 650 factors that allow to make some steps in about 50 sequences.
  • Michael Roedel in a couple of sequences.
  • Jim Howell, mainly in the sequence 966.
  • Some other people; sorry for the lack of their names.
